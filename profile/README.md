# grom-labs

Open tools for treating the hardware you own as the little computer it already is: root, a shell, screen access and small tweaks on top of stock firmware — for local development and tinkering.

We start with FPV goggles, but the idea isn't device-specific: consumer gear runs real operating systems, and you should be able to open your own.

## Projects

* [toolya](https://github.com/grom-labs/toolya) — a root + adb enabler and local-dev toolkit. First target: FPV goggles. Live at [toolya.dev](https://toolya.dev/).
* [natartos](https://github.com/grom-labs/natartos) (early) — a framework for modifying device firmware reversibly, built on top of a root foothold like toolya's.

## What this is (and isn't)

* For hardware you own. Interoperability and local development — the same spirit as jailbreaking a phone you bought.
* We publish our own code only. No vendor firmware or binaries live here.
* Not affiliated with, authorized by, or endorsed by any device vendor. Product names, where they appear in a project, are trademarks of their owners and used only to say what a tool works with.

## Host your project here

Wrote something for a device you own — an app for your goggles, a tool, a mod? It can live under grom-labs next to ours. You keep authorship, the license and your own donations, and you can take the repo back any time. See [HOSTING.md](https://github.com/grom-labs/.github/blob/main/HOSTING.md).
